# 🌍 World Problem Solver – Waste Management System

> An AI-powered web application designed to help people report and manage waste-related problems in their communities.

## 🚀 About the Project

**World Problem Solver** is a smart Waste Management System built with **Python Flask, HTML, SQLite and Gemini AI**.

The goal of this project is to make it easier for users to report waste problems and help manage those problems digitally.

## ✨ Features

- 🗑️ Report waste-related problems
- 📋 Store reported problems in a database
- 📊 Track problem information and status
- 🤖 AI-powered assistance using Gemini
- 💾 SQLite database integration
- 🌐 Simple and responsive web interface
- 🔐 Environment variable support for API keys

## 🛠️ Technologies Used
